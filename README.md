✨ Why GitHub Pusher?
Pushing a project to GitHub usually means: open terminal → git init → git add → git commit → set remote → deal with tokens → push → fix auth errors → try again.

GitHub Pusher does all of that in one click — with a beautiful dark UI, drag & drop, real-time logs, and human-readable error messages.

🎯 Features
🖱️ Drag & Drop — just drop your .zip onto the window (or click to browse)

🔐 Token validation before push — checks your token, scopes and repo permissions before touching git, so you get clear errors instead of cryptic 403s

🌿 Custom branch — push to main, master, or any branch you want

💬 Custom commit message

⚡ Force push option — replace existing content on a branch when needed

📜 Live terminal-style log — see every git command and its output in real time

🎨 Modern dark UI — built with CustomTkinter, smooth and clean

🖥️ Cross-platform — Windows, Linux, macOS

🧠 Smart error hints — tells you why it failed (bad token, no write access, non-fast-forward, etc.) and how to fix it

🔒 Token safety — token is masked in the UI and in logs (***)
